# 番剧记录（Anime Tracker）

一个全中文、全离线的 Windows 桌面应用：按「年 × 季度」记录你追的每部番剧和看到第几集，并支持统计、评分短评、下载目录识别、Excel 导入导出。仅「老番搜索 Bangumi」需要联网。

## 快速开始

- **绿色版**：双击 `dist\番剧记录-0.1.0-绿色版.exe` 即可使用，无需安装任何环境。
- **开发运行**：`npm start`（需要 Node.js）
- **运行测试**：`npm test`

## 核心功能

- **季度组织**：左侧按 1 月 / 4 月 / 7 月 / 10 月分组，和你的 Excel 习惯一致。
- **番剧条目**：名称、季度、状态（在看 / 看完 / 弃番 / 搁置 / 想看）、当前集数、总集数、每周更新日。
- **进度操作**：卡片「＋1 集」一键推进，到总集数自动标记看完；「看完」一键完成；编辑弹窗随时修改。
- **当季选番**：添加时默认从「当季新番」列表里选，自动填充集数、更新日、简介、封面等信息。
- **老番搜索**：切到「搜 Bangumi」标签页，输入番名自动从 Bangumi 补全总集数、简介、封面、评分；断网时自动降级为手动填写。
- **统计看板**：追番总数、在看/看完、累计集数、完成率、平均评分、高分 Top5、各季度集数对比。
- **下载目录识别**：扫描你的下载文件夹（如 `D:\ANIME\花织`），自动识别番名与已下载集数，提示「已下载第 X 集，但只看到第 Y 集」。
- **导入 / 导出**：
  - 导入旧的 `已经 将要 看.xlsx`（年 → 季度 → 番名结构），自动去重；
  - 导出排版精美的 Excel（总览 / 季度明细 / 全部记录三个表，含样式、自动筛选、进度条）；
  - 导出 / 导入 JSON 完整备份（导入前自动备份当前数据，可随时恢复）。

## 新番数据来源

- 默认读取 `D:\ANIME\日本TV动画信息` 目录（可在「设置」里修改路径）。
- 数据优先级：`scripts\_runtime\data\bangumi_YYYYMM.json` → 季度文件夹里的「*新番信息.json」→ 「*新番信息.docx」兜底。
- 管线每次生成季度新番 docx 时，会同步在季度文件夹写入同名 JSON，应用启动 / 每 10 分钟 / 窗口聚焦时会自动检测并导入新季度（弹出提示，立即可在「添加番剧 → 当季新番」选用）。

## 数据与备份

- 数据保存在 `%APPDATA%\anime-tracker\data.json`（应用内「设置」页可查看路径）。
- 每次修改都会刷新当日备份（`backups\`，保留最近 30 份）；数据损坏时会自动从最近备份恢复。
- 如需多设备同步，把整个 `anime-tracker` 数据目录放入同步盘即可。

## 项目结构

```
anime-tracker/
├── main.js / preload.js      # Electron 主进程与安全桥
├── lib/
│   ├── store.js              # 数据持久化（原子写入 + 自动备份）
│   ├── seasonData.js         # 季度数据源（bangumi JSON / docx 兜底）
│   ├── docxParser.js         # 解析新番信息 docx
│   ├── bangumi.js            # Bangumi 搜索 API 客户端
│   ├── scanner.js            # 下载目录扫描与文件名解析
│   └── excel.js              # Excel 导入（新旧格式）与样式化导出
├── renderer/                 # 界面（原生 HTML/CSS/JS，深色主题）
└── tests/                    # 单元测试（node --test）
```
