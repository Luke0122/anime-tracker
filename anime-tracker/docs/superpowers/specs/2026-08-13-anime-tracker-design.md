# 番剧记录（Anime Tracker）设计文档

- 日期：2026-08-13
- 状态：已向用户展示方案，按推荐默认（半自动 + 全离线）推进
- 目标平台：Windows 桌面

## 1. 目标

一个桌面端软件，记录用户每个季度看了哪些番剧、每部看到第几集；并在此基础上提供评分、统计、下载文件夹识别、Excel 导入导出等增强功能。

## 2. 核心需求

1. 按「年 × 季度」（1月 / 4月 / 7月 / 10月）组织番剧，与用户现有 Excel 习惯一致。
2. 番剧条目包含：名称、所属季度、状态（在看/看完/弃番/搁置/想看）、当前集数、总集数、每周更新日、评分（1-10）、一句话短评。
3. 进度操作：+1 集、标记看完、手动修改集数。
4. 搜索与筛选（按名称、状态、季度）。
5. 导入现有 Excel「已经 将要 看.xlsx」（年→季度→番名结构）。
6. 下载文件夹识别：扫描用户选择的目录（如 `D:\AnimeDownloads`），解析视频文件名中的番名与集数，提示「已下载 X 集但看到 Y 集」。
7. 统计看板：季度/年度追番数、总集数、完成率、平均评分。
8. 导出备份：JSON / Excel。

## 3. 技术选型

- Electron（主进程 + 渲染进程），打包后可双击运行；不依赖系统 Python。
- 渲染层：原生 HTML/CSS/JS（无前端框架），减少依赖与构建步骤。
- 数据存储：本地 JSON 文件（原子写入 + 自动备份），数据量小、可手动复制同步/备份。
- Excel 读取：`xlsx`（SheetJS）纯 JS 库。
- 无网络依赖：应用运行期间完全不联网。

## 4. 数据模型

```json
{
  "version": 1,
  "anime": [
    {
      "id": "uuid",
      "title": "上低音号3",
      "season": "2024-04",
      "status": "watching",
      "episode": 5,
      "totalEpisodes": 13,
      "updateDay": 3,
      "rating": 9,
      "comment": "吹奏乐太棒了",
      "folders": ["D:\\AnimeDownloads"],
      "createdAt": "2026-08-13T00:00:00+08:00",
      "updatedAt": "2026-08-13T00:00:00+08:00"
    }
  ]
}
```

- `season` 键：`YYYY-MM`，MM 取值 01 / 04 / 07 / 10。
- `status` 取值：`watching` / `completed` / `dropped` / `on_hold` / `plan`。
- `updateDay`：0=周日 … 6=周六，可为空。
- 数据文件默认存于 Electron `userData` 目录（Windows 为 `%APPDATA%\anime-tracker\data.json`），应用内展示路径并提供导出。

## 5. 架构与模块

- `main.js`：Electron 主进程。创建窗口、注册 IPC、负责磁盘读写、目录扫描、Excel 解析。
- `preload.js`：`contextBridge` 暴露安全的 `window.api` 给渲染进程。
- `renderer/index.html` + `styles.css` + `app.js`：全部 UI 与交互。
- `lib/store.js`：JSON 持久化（读/写/原子替换/每日备份）。
- `lib/scanner.js`：解析视频文件名（`[组][番名][集数]` 等常见模式），返回 番名→集数列表。
- `lib/excel-import.js`：读取 xlsx，按 年→季度→番名 结构转为条目。

### IPC 接口

- `anime:list` / `anime:add` / `anime:update` / `anime:delete` / `anime:bump`
- `scan:pickFolder` / `scan:run(folder)`
- `data:export(kind)`（JSON/Excel）/ `data:importExcel()` / `data:getPath`

## 6. 界面布局

- 左侧栏：季度列表（最新在前）+「全部」「统计」入口。
- 主区域：季度标题 + 番剧卡片网格。卡片含：名称、状态徽章、进度条（第 X/Y 集）、+1 按钮、编辑按钮。
- 顶栏：搜索框、状态筛选、添加番剧、导入导出菜单、数据路径提示。
- 弹窗：添加/编辑番剧表单（名称、季度、状态、集数、总集数、更新日、评分、短评、关联文件夹）。
- 统计视图：年度/季度汇总卡片（部数、集数、完成率、平均分）+ 条目列表。
- 扫描视图：选择目录 → 显示识别结果，与现有条目匹配，可一键添加到对应季度。

## 7. 错误处理与边界

- JSON 损坏时自动备份坏文件并从最近备份恢复，不丢失数据。
- Excel 导入支持预览与「跳过已存在」的合并策略。
- 文件名解析失败时进入「未识别」列表，可手动指定番名。
- 集数不超过总集数（若填写）；+1 到总集数时自动标记看完。
- 所有写操作先写临时文件再原子替换。

## 8. 测试与验收

- 自动化：存储模块读写/损坏恢复、扫描器文件名解析、Excel 导入解析（对样例文件断言）。
- 手动验收：启动应用 → 添加番剧 → +1 进度 → 导入现有 Excel → 扫描 `D:\AnimeDownloads` → 查看统计 → 导出备份。
- 交付：`npm start` 可运行 + 一键启动脚本 `启动番剧记录.cmd`；后续可打包 exe。
